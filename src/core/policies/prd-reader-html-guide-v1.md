# 零基础阅读 HTML 生成指南 v1

## 目标与责任边界

`LOCAL_HTML` 不是把 `PRD.md` 换一种文件格式，也不是宣传页。Host Agent
必须从已经 Ready 的精确 `PRD.md` 生成一份派生阅读视图，让第一次接触项目、
不了解系统架构，但需要参与产品或研发评审的人，能按顺序建立正确理解。

`PRD.md` 始终是唯一产品事实与编辑真源。HTML 可以重排、分层、解释、举例和
压缩重复，但不得改变产品含义、补造事实、扩大范围，或把产品决定写成已经实现、
测试、灰度、上线或获得真实用户验证。HTML 生成与浏览器检查只证明阅读视图已
生成并通过对应检查，不重新批准 PRD 内容。

## 生成前先分类

完整阅读精确 Ready PRD，并在生成时区分：

- 已验证事实；
- 产品判断；
- 目标方案；
- 用户行为；
- 需求范围；
- 非目标；
- 依赖的其他 PRD 或外部条件；
- 尚未验证、未执行或仍未知的内容。

不得为了简化而删除会改变目标、范围、规则、责任、异常处理、迁移、验收或状态
边界的信息。研发字段、数据库、类设计和内部算法只有在影响产品行为时才进入主
阅读路径。

## 默认阅读路径

复杂 PRD 优先使用以下顺序；不适用的章节可以合并或省略，但不能伪造内容：

1. **30 秒摘要**：事情是什么、为什么做、准备怎么做。
2. **当前实现**：参与者、信息流动顺序和一个具体例子。
3. **关键问题**：每个问题写清原因、后果和受影响的人。
4. **行业参考**：参考对象解决什么、可采用什么、不能照搬什么。
5. **目标方案**：责任分工、新链路和保留的现有能力。
6. **核心对象**：首次出现时用大白话解释，并展示实例或状态变化。
7. **用户页面体验**：执行中、完成、失败和中断分别看到什么。
8. **迁移对应关系**：当前内容、当前方式、目标对象、目标展示和迁移归属。
9. **需求边界**：本需求负责、不负责，以及相关 PRD 的责任。
10. **迁移与完成标准**：Shadow、灰度、回滚和退出旧机制的条件。

优先使用“当前 → 目标”对照。一个段落只讲一件事。抽象概念必须有具体例子。
术语首次出现时，先解释产品含义，再给 Machine Name。表格只用于稳定比较和映射。

## 页面表达

- 页面是阅读文档，不是宣传网站。
- 使用一个明确标题、一段导语和可在一屏内扫完的摘要。
- 使用短标题、有限宽正文、舒适行高和明显章节边界。
- 流程只使用简单方框与箭头。
- 当前与目标使用双栏对照；手机端改为单栏。
- 迁移关系和责任边界使用带局部横向滚动容器的表格。
- 重要结论只使用少量高亮提示框。
- 颜色控制在三至四个主色角色，保证正文对比度。
- 不使用复杂动画、视差、全屏滚动或大面积空白。
- 不使用 JavaScript。
- 不使用外部字体、样式、脚本或图片；必要图片使用带非空 `alt` 的 `<img>`
  并嵌入为安全 `data:` URL，不通过 CSS `url(...)` 加载。

## 机械交付合同

Host Agent 将 HTML 写入当前 Run 的 `work/` 目录，再把精确
`html_source_ref` 交给 `handoff`。该引用必须包含 `path`、`hash` 和与当前
Candidate 相同的 `version`。

HTML 必须：

- 使用 `<!doctype html>`；
- 在唯一 `<html>` 元素上声明
  `data-bpg-reader-view="zero-context-v1"`；
- 包含 device-width viewport、唯一 `title`、`header`、`nav`、`main` 和
  `footer`；
- 包含至少一个带 `id` 的阅读章节，且导航锚点全部有效；
- 在 `footer` 中提供 `href="PRD.md"` 的原始 PRD 相对链接；
- 使用包含 `@media`、`max-width` 和 `overflow-x` 控制的内联 CSS；
- 将宽表格包在局部横向滚动容器中，不能让整页横向溢出；
- 保持 UTF-8，总大小不超过 2 MB。

Controller 只检查安全、结构、精确引用和交付一致性，不判断摘要是否准确或阅读
路径是否真正有效。语义责任仍属于 Host Agent；真实人类阅读仍是独立证据。

## 浏览器检查

生成后必须使用真实浏览器检查：

- 桌面视口宽度 1440px；
- 手机视口宽度 390px；
- 整页没有横向溢出；
- 中文没有截断、遮挡或重叠；
- 表格可读并只在自身容器内横向滚动；
- 导航锚点有效；
- `PRD.md` 原文链接有效；
- 控制台没有错误。

Host 无法使用真实浏览器时，必须把浏览器验证报告为 `NOT_RUN`，不能用静态检查
冒充完成。

## 专项转换任务的最终汇报

当用户只要求制作零基础阅读 HTML 时，最终仅汇报：

- HTML 文件路径；
- 页面采用的阅读结构；
- 1440px 桌面与 390px 手机验证结果；
- 原始 PRD 是否被修改。
