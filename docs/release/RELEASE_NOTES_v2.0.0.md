# Better Product Graph 2.0.0 — Replacement Architecture

`2.0.0` makes the BPG 2.0 single-PRD architecture the default and removes the legacy 0.x route.

## What is included

- One complete path from Signal & Route through product understanding, problem and decision Candidates, independent Review, product-system planning, one formal or experimental PRD, Ready, optional Local HTML Handoff, and retrospective.
- Six explicit decision outcomes: `STOP`, `WAIT`, `RESEARCH`, `EXPERIMENT`, `COMMIT_NOW`, and `FUTURE_ROADMAP`.
- Exact Run/runtime binding, content-addressed immutable Candidates, independent Reviewer identities, lead-Agent-owned return routing, stale-evidence rejection, and idempotent recovery.
- Source-first Mermaid/SVG Candidate visuals. HTML is generated only as a selected Handoff format after content Review.
- Truthful Product Evals degradation: the Generator is `NOT_IMPLEMENTED`; `REQUIRED` blocks Ready and no simulated Eval Pack is accepted.
- Deterministic Codex and Claude marketplace assets built from exact clean development commit `c79eaff4ba59de74bb8d9e572d6bc800eec77720`.
