# 常用报销信息快速选择

## 目标

员工提交报销时可以选择最近使用过的收款与开票信息，减少重复输入；过期或被删除的信息不能继续使用。

## 产品规则

- 最近使用的三条有效信息按使用时间倒序显示。
- 员工可以选择历史信息，也可以新建信息。
- 选择后编辑只影响本次报销，不修改历史记录。
- 已过期、已删除或无权限的信息不显示。
- 提交前必须再次展示本次实际使用的信息。

- [x] 有历史信息的主流程
- [x] 空列表与新建入口
- [x] 信息失效后的处理
- [x] 本次编辑不回写历史
- [ ] 多语言文案
- [ ] 旧客户端兼容

## 验收

- 存在有效历史信息时，员工能在填写页直接选择。
- 没有可用历史信息时，页面提供新建入口。
- 历史信息在提交前失效时，系统阻止提交并要求重新选择。
- 选择后编辑不会改变历史记录。

## 风险与未知

风险是信息在页面打开后失效。当前未知是旧客户端能否显示失效原因；无论客户端版本如何，都不能继续提交失效信息。

## 下一步

先核对历史信息失效与页面刷新两个场景，再由客户端负责人确认兼容范围。本需求不改变报销审批规则。
