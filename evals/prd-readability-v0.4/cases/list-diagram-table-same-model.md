# 订阅取消生效

## 目标

让用户知道取消订阅何时生效，以及取消处理中、已取消和取消失败分别意味着什么。

## 状态列表

- `ACTIVE`：订阅有效，可以发起取消。
- `CANCEL_REQUESTED`：已收到取消请求，等待支付渠道确认。
- `CANCELLED`：支付渠道确认成功，不再续费。
- `CANCEL_FAILED`：支付渠道拒绝或超时，订阅仍有效。

## 状态图

```text
ACTIVE
  └─ 用户取消 → CANCEL_REQUESTED
                    ├─ 渠道确认 → CANCELLED
                    └─ 渠道拒绝或超时 → CANCEL_FAILED
```

## 状态表

| 状态 | 含义 | 下一步 |
|---|---|---|
| `ACTIVE` | 订阅有效 | 用户可以发起取消 |
| `CANCEL_REQUESTED` | 已收到取消请求，等待支付渠道确认 | 等待结果 |
| `CANCELLED` | 支付渠道确认成功，不再续费 | 无 |
| `CANCEL_FAILED` | 支付渠道拒绝或超时，订阅仍有效 | 用户可以重试 |

## 验收

- 用户发起取消后先看到“取消处理中”。
- 支付渠道确认成功后显示“已取消”。
- 渠道拒绝或超时后显示“取消失败，订阅仍有效”。
