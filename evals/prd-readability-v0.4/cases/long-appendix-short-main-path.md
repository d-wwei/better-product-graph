# 门店取货码

## 一句话说明

用户到店后出示一次性取货码，店员核对成功即可交付商品；核对失败时商品不能被标记为已取货。

## 先看主路径

1. 订单备货完成后，用户收到取货码。
2. 店员扫描取货码并核对订单与门店。
3. 核对成功后订单变为“已取货”，取货码立即失效。

## 关键失败与恢复

- 取货码过期：用户刷新订单页获取新码。
- 门店不匹配：页面指出正确门店，不允许交付。
- 网络中断：不显示成功，店员恢复网络后重新核对。
- 商品缺失：店员发起门店异常处理，不消费取货码。

## 核心验收

- 一个取货码只能成功使用一次。
- 只有订单所属门店可以核销。
- 没有服务端成功结果时不能显示“已取货”。

## 附录 A：提示文案参考

| 场景 | 用户端文案 | 店员端文案 |
|---|---|---|
| 尚未备货 | 商品准备中，请稍后再来 | 订单尚未完成备货 |
| 可以取货 | 请向店员出示取货码 | 请扫描用户取货码 |
| 码已过期 | 取货码已刷新，请使用新码 | 此码已过期，请用户刷新 |
| 门店错误 | 此订单应在其他门店领取 | 当前门店无法核销此订单 |
| 已被使用 | 商品已于记录时间取走 | 此码已经核销 |
| 网络异常 | 暂时无法确认，请稍后重试 | 网络异常，未完成核销 |
| 商品缺失 | 门店正在处理商品异常 | 请发起商品缺失处理 |
| 订单取消 | 订单已取消，无法取货 | 已取消订单不能核销 |

## 附录 B：事件字段参考

| 事件 | 必填字段 | 用途 |
|---|---|---|
| 取货码展示 | 订单、门店、码版本 | 观察用户是否进入取货流程 |
| 扫码开始 | 订单、门店、店员终端 | 观察店员操作入口 |
| 核对成功 | 订单、门店、服务端结果 | 计算成功率 |
| 核对失败 | 订单、门店、失败类型 | 定位失败原因 |
| 新码生成 | 订单、旧码版本、新码版本 | 检查过期恢复 |
| 异常处理发起 | 订单、门店、异常类型 | 跟踪门店异常 |

## 附录 C：多语言关键词

下列词组需要在语言包中保持一致含义：取货码、已过期、已核销、门店不匹配、备货中、商品缺失、网络异常、已取货。具体翻译由本地化流程维护，本 PRD 只规定用户可理解的状态含义。

## 不在范围

本需求不改变门店备货、退款、换货或店员账号权限规则。
