# 批量任务暂停与恢复

## 摘要

运营人员需要暂停正在执行的批量任务，并在确认后从安全检查点恢复。暂停不是取消；恢复也不是重新创建任务。

## 用户问题

当外部数据源异常时，运营人员现在只能让批量任务继续运行或直接取消。继续运行可能扩大错误结果；取消后又必须从头执行。我们需要一个可以暂停、检查和恢复的中间状态。

## 状态说明（第一处）

| 状态 | 含义 | 可执行动作 |
|---|---|---|
| RUNNING | 正在处理下一批数据 | 暂停 |
| PAUSE_REQUESTED | 已请求暂停，等待当前批次结束 | 查看 |
| PAUSED | 已停在安全检查点 | 恢复、取消 |
| RESUME_REQUESTED | 已请求恢复，等待重新校验 | 查看 |
| FAILED | 暂停或恢复失败 | 重试、取消 |

只有 `PAUSED` 可以恢复。`PAUSE_REQUESTED` 期间继续完成当前批次，但不能领取新批次。`RESUME_REQUESTED` 必须重新校验数据源和操作者权限。

## 主流程

运营人员在任务详情页点击“暂停”。系统把任务改为 `PAUSE_REQUESTED`，当前批次完成后写入检查点，再改为 `PAUSED`。页面在状态变化前只显示“暂停处理中”，不能提前显示“已暂停”。

运营人员点击“恢复”后，系统把任务改为 `RESUME_REQUESTED`，重新校验数据源和操作者权限。校验通过后从最近检查点继续，并改为 `RUNNING`；校验失败则改为 `FAILED`，不领取新批次。

## 暂停规则（第二处）

暂停时要先等待当前批次结束。等待期间状态叫 `PAUSE_REQUESTED`。当前批次结束后保存检查点，保存成功才叫 `PAUSED`。因此运营人员点击按钮以后，不是马上暂停，也不能马上恢复。只有 `PAUSED` 才能恢复。

如果检查点保存失败，任务叫 `FAILED`。这时可以重试暂停，也可以取消任务。重试不能重复处理已经成功完成的批次。

## 恢复规则（第三处）

恢复只适用于 `PAUSED`。点击恢复以后状态先叫 `RESUME_REQUESTED`，系统要再次检查数据源，也要检查操作者权限。两项都通过才回到 `RUNNING`。任何一项不通过都进入 `FAILED`，而且不能领取新批次。

恢复是从最近的检查点继续，不是创建新任务，也不是从第一批开始。

## 状态与按钮对照（第四处）

| 当前状态 | 暂停按钮 | 恢复按钮 | 取消按钮 |
|---|---|---|---|
| RUNNING | 显示 | 隐藏 | 显示 |
| PAUSE_REQUESTED | 禁用 | 隐藏 | 显示 |
| PAUSED | 隐藏 | 显示 | 显示 |
| RESUME_REQUESTED | 隐藏 | 禁用 | 显示 |
| FAILED | 隐藏 | 视失败阶段而定 | 显示 |

这里再次强调：`PAUSED` 才可以恢复；`PAUSE_REQUESTED` 只是暂停处理中；`RESUME_REQUESTED` 只是恢复处理中。

## 异常和限制（第五处）

- 当前批次不会被中途截断。
- 暂停处理中不会领取新批次。
- 保存检查点失败会进入 `FAILED`。
- 恢复前要重新检查数据源和权限。
- 恢复失败不会领取新批次。
- 只有 `PAUSED` 能恢复。
- 取消与暂停不是同一件事。
- 本需求不改变单批次内部的重试算法。

## 验收标准（第六处）

1. Given 任务是 `RUNNING`，When 运营人员点击暂停，Then 任务先变为 `PAUSE_REQUESTED`，当前批次完成后才变为 `PAUSED`。
2. Given 任务是 `PAUSE_REQUESTED`，When 当前批次未完成，Then 系统不领取新批次，页面不显示“已暂停”。
3. Given 任务是 `PAUSED`，When 运营人员点击恢复，Then 任务先变为 `RESUME_REQUESTED` 并重新校验。
4. Given 恢复校验失败，When 系统处理完成，Then 任务变为 `FAILED` 且不领取新批次。
5. Given 任务不是 `PAUSED`，When 用户尝试恢复，Then 系统拒绝并说明当前状态不能恢复。
6. Given 检查点保存失败，When 用户重试暂停，Then 已完成批次不会被重复处理。

## 给研发的再次说明（第七处）

研发实现时请注意，暂停不是立即生效。按钮触发 `PAUSE_REQUESTED`；当前批次结束并成功写检查点后才是 `PAUSED`。恢复也不是立即生效，必须先进入 `RESUME_REQUESTED`，通过数据源和权限校验以后才回到 `RUNNING`。如果失败就是 `FAILED`。特别需要记住，只有 `PAUSED` 可以恢复。

## 不在范围

本次不改变任务取消、单批次重试、检查点存储格式或调度器并发策略。
