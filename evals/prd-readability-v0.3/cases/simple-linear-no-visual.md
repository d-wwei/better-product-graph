# 修改收货地址

## 一句话说明

订单尚未发货时，用户可以修改一次收货地址；发货后不再允许修改。

## 用户为什么需要它

用户下单后可能发现门牌号或联系电话填写错误。当前只能取消订单重新购买，既浪费时间，也可能错过库存。

## 产品规则

1. 订单状态为“待发货”时，订单详情页显示“修改收货地址”。
2. 用户提交新地址后，系统立即替换本订单的收货地址，并显示“修改成功”。
3. 每个订单最多成功修改一次。
4. 订单进入“已发货”后，入口消失；用户通过旧链接进入时，页面说明“订单已发货，不能再修改地址”。

## 验收

- 待发货订单第一次提交有效地址后，详情页显示新地址。
- 同一订单再次尝试修改时，系统拒绝并说明次数限制。
- 已发货订单不显示入口，也不能通过旧链接修改。

## 不在本次范围

本次不改变配送范围、运费规则或已经发货订单的转寄流程。
