# 研究资料室访问权限

## 产品目标

让跨机构研究团队在同一资料室共享公开资料、项目草稿、受限样本和发布包，同时让每种身份只执行被授权的动作。用户应能在操作前判断自己可以做什么，越权时得到可解释且不改变资料的结果。

## 阅读导航

* 需要判断某个身份能否操作，直接查看[权限矩阵](#权限矩阵)。
- 需要评估开放问题，查看[风险与未知](#风险与未知)。
- 需要了解验证安排，查看[下一步](#下一步)。

## 产品规则

- 权限同时取决于当前身份、资料范围、动作和附加条件，不能只凭一个角色名称推断。
- “项目内”只包含用户当前加入的项目；跨项目访问必须另行获得明确授权。
- 导出和删除属于高影响动作，即使用户能查看资料，也不自动获得这两项能力。
- 条件不满足时拒绝操作并说明缺少的授权或步骤，原资料及共享状态保持不变。
- 权限变更对下一次操作立即生效，已经生成的合规发布包按其独立有效期处理。

## 权限矩阵

| 身份 | 资料范围 | 动作 | 条件 | 可见结果 |
|---|---|---|---|---|
| 访客 | 公开资料 | 查看 | 链接仍有效 | 打开只读内容 |
| 访客 | 公开资料 | 下载 | 资料允许下载 | 获得带来源说明的文件 |
| 访客 | 项目草稿 | 查看 | 无 | 拒绝并提示申请加入项目 |
| 项目成员 | 公开资料 | 查看 | 已登录 | 打开只读内容 |
| 项目成员 | 项目草稿 | 查看 | 属于当前项目 | 打开最新可见版本 |
| 项目成员 | 项目草稿 | 添加批注 | 属于当前项目 | 批注进入讨论区 |
| 项目成员 | 项目草稿 | 上传新版本 | 被指定为贡献者 | 新版本进入待审状态 |
| 项目成员 | 受限样本 | 查看 | 已签署当前用途承诺 | 打开脱敏预览 |
| 项目成员 | 受限样本 | 导出 | 无 | 拒绝并提示联系资料管理员 |
| 项目负责人 | 项目草稿 | 上传新版本 | 属于当前项目 | 新版本进入待审状态 |
| 项目负责人 | 项目草稿 | 批准共享 | 版本已完成必要评审 | 项目成员可见范围更新 |
| 项目负责人 | 发布包 | 创建 | 发布信息完整 | 生成待合规确认的发布包 |
| 资料管理员 | 受限样本 | 查看 | 管理范围包含该资料 | 打开原始资料并记录访问 |
| 资料管理员 | 受限样本 | 授权项目访问 | 用途和期限已确认 | 项目获得限时脱敏预览 |
| 资料管理员 | 受限样本 | 删除 | 保留期届满且无冻结要求 | 删除进入待复核状态 |
| 合规复核员 | 发布包 | 查看 | 被指派本次复核 | 打开包内容与来源记录 |
| 合规复核员 | 发布包 | 批准对外发布 | 所有开放项已关闭 | 发布包获得明确有效期 |
| 审计查看者 | 访问记录 | 查看 | 审计范围仍有效 | 查看只读访问与变更记录 |

## 可观察验收

- 任意矩阵行都能用对应身份、资料、动作和条件复现允许或拒绝结果。
- 同一项目成员查看草稿成功，但导出受限样本被拒绝且资料不发生变化。
- 用途承诺过期后，再次打开受限样本会提示续签，不沿用旧页面状态。
- 发布包缺少合规确认时不能对外开放；确认后显示有效期和确认角色。
- 被移出项目的用户下一次提交批注或版本时收到拒绝，已有资料不被改写。
- 审计查看者只能读取记录，不能借由记录页面打开受限样本正文。

## 风险与未知

主要风险是用户同时拥有多个身份时误解最终权限；页面应在高影响操作前展示本次采用的身份、资料范围和条件。当前未知是跨机构合规复核是否允许委托代理人，以及已下载文件到期后的组织处置规则；这两项不在首轮自动化范围内。

## 下一步

从矩阵中抽取允许、条件未满足、明确拒绝和权限刚变更四类共十二个场景，由研究负责人、资料管理员和合规复核员共同走查。代理委托与下载后处置先记录为待决策，不假定已有能力。
