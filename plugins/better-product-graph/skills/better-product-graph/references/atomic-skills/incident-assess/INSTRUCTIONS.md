# Incident Assess — Agent Instructions v0.1

Run only through the public Skill and Controller. Assess the exact Signal and available local evidence. Produce a concise incident assessment containing summary, severity, impact, reproduction, scope, missing data, next action, and `runtime_status=WAITING_ENGINEERING`.

Use `NOT_AVAILABLE` for required information that cannot be verified. Do not claim a remote ticket, message, or engineering acknowledgement. The runtime will create only an append-only local verification packet and Null/local handoff in this release.
